Como preparar o Excel

Abas reconhecidas pelo sistema

O sistema lê somente as abas com esses nomes exatos (sem distinção de maiúsculas). Demais abas são completamente ignoradas.

Estrutura das colunas

A B CHAVE C D E EXCLUSÃO F PROFAT G VALOR
cab. (qualquer) Código do procedimento (qualquer) (qualquer) Condição de exclusão Código Profat Valor unitário (R$)
1 … 10101012 … … 00012345 42,50
2 … 20202025 … … 00054321 187,00
3 … 30303038 … … EXCLUÍDO — —
Coluna B — chave de busca usada na comparação com o XML
Colunas F e G — valores lidos para o resultado
Demais colunas — ignoradas

Regras de leitura

1
A primeira linha de cada aba é tratada como cabeçalho e ignorada. Os dados começam na linha 2.
2
O código na coluna B é limpo automaticamente — zeros à esquerda, pontos e traços são removidos antes da comparação com o XML.
3
Linhas em que a coluna E tenha qualquer conteúdo são ignoradas. Use essa coluna para marcar procedimentos excluídos ou inativados.
4
O valor monetário na coluna G aceita vírgula ou ponto como separador decimal. Formatação de moeda (R$, espaços) é ignorada.
5
O Profat (coluna F) é normalizado com 8 dígitos, preenchendo zeros à esquerda quando necessário.
6
Tolerância de R$ 0,02 na comparação — diferenças abaixo disso são classificadas como CORRETO para absorver arredondamentos de centavos.
Abas com nomes diferentes dos listados acima são completamente ignoradas, mesmo que contenham dados válidos. Verifique a nomenclatura antes de carregar o arquivo.
